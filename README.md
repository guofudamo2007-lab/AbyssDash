## 🌊 核心特色玩法

* **流体动力学操控：** 摒弃死板的坐标平移，采用“按住下潜，松开上浮”的深海浮力模拟。游戏角色随垂直运动速度引入 **Pitch 俯仰角自适应旋转矩阵**，操作反馈极具灵动的流体质感。
* **次世代视觉心流：** 吞噬具备独立多边形尾鳍及眼部微观动态的发光潜鱼积攒狩猎值，满怒即可触发【猩红冲刺 RUSH】——激活超高速镜头动态线条、无敌霸体与全屏暗礁碎裂特效。
* **高阶攻防生态：** 引入【电磁磁铁】自动吸附方圆 300px 内的所有鱼群；【量子护盾】可完美抵御一次致命伤害；超过 300 分后，将遭遇具备**纵向残差寻轨算法**的智能水雷，极限拉满操作上限。
* **全生态动态演变：** 独创 **Depth 深度矩阵**，随着潜入深渊的深度增加，天空光 rays、远山、前景植物以及海水色域将平滑陷入漆黑的午夜超深海区，并叠加动态**径向迷雾暗角 (Vignette)**。

## 🛠️ 技术亮点与工程实践

本项目拒绝依赖任何第三方现代游戏引擎（如 Cocos/Egret）或重量级框架，纯手写底层物理、碰撞判定、渲染管线与音频合成，核心攻坚了以下工业级痛点：

| 工程痛点 | 产生的现象 | 解决方案与架构 |
| :--- | :--- | :--- |
| **视口跨端缩放** | 传统 HTML5 游戏在面对全面屏手机、iPad、折叠屏时，常因固定像素宽高导致 UI 字体错位或被画面裁剪。 | **高级容器查询架构 (Container Query Units)：** 将外层包裹器声明为 size 容器，UI 抛弃传统的 px 和 vw，全量改用全新的 `cqw` / `cqh` 容器单位进行相对缩放，实现完美的长宽比动态保真。 |
| **全生态动态变色** | 随着跑酷距离增加，单一的背景色容易产生视觉疲劳，且无法体现“下潜深渊”的逼真深海层次。 | **色域空间线性插值算法 (Color Space Lerp)：** 提取深度系数，让天空光、山脉、前景植物的 RGB 像素随分数实时平滑演变，并在中后期无缝渲染由内向外的**径向渐变迷雾暗角 (Radial Vignette)**。 |
| **运动俯仰角缺失** | 鲨鱼在垂直位移（Y轴）剧烈变动时，若角度始终水平，会产生极其僵硬的空中漂移感。 | **动态刚体旋转 (Rigid Body Rotation)：** 每帧实时抓取 $shark.velocity$ 运动矢量，通过弧度矩阵叠加 $ctx.rotate$。实现操控时“下潜低头、上浮挺胸”的流体仿生动态。 |
| **视差无缝滚屏** | 前景植物在移出画布左侧进行循环再生成时，非线性计算容易导致物体边缘突兀闪烁、产生断层。 | **双模余数自适应公式 (Modulus Wrapping)：** 重写坐标滚动公式 `((i * 250 - frame * 0.5) % (w + 250) + (w + 250)) % (w + 250) - 100`，物理抹平边缘越界，实现永不断层的丝滑无缝跑马灯滚动。 |
| **移动端强行竖屏** | 手机玩家误以竖屏方式点开游戏时，由于 Canvas 是 900×500 宽屏比例，会导致画面被严重挤压变形。 | **移动端横屏防呆锁 (Orientation Locker)：** 拦截 `touchstart` 并利用 CSS 媒体查询 `@media screen and (orientation: portrait)`，在竖屏时强制拉起赛博风的全屏 Overlay 提示，自动阻断不规范手势。 |
| **引力场物理计算** | 磁铁吸附小鱼时，如果直接更改坐标会产生生硬的瞬间瞬移。 | **线性插值缓动 (Lerp Approaching)：** 基于 Math.hypot 建立半径 300px 的电磁感应区，对区域内小鱼运用弹性缓动插值算法，实现丝滑的平滑吸附特效。 |
| **刷新率依赖** | 144Hz/240Hz 屏幕下游戏运行速度是 60Hz 的数倍，导致高刷屏玩家必定暴毙。 | **工业级时间步长 (Fixed Time Step)：** 引入时间累加器（Accumulator），强制逻辑帧锁定 120Hz 更新，彻底剥离物理逻辑与渲染帧率。 |

## 💻 技术栈

* **文本视觉：** 远程无缝挂载 Google Web Fonts 工业级赛博风格字体（Orbitron / Rajdhani）。
* **渲染层：** HTML5 `<canvas>` 2D API 纯代码绘制特效（双重矩阵相机震屏、径向自适应暗角、刚体俯仰角转动、鱼体多边形微观渲染、吃分飘字、发光粒子、视差远山、无缝海藻）。
* **音频引擎：** Web Audio API（基于代码手搓合成器底层，生成三角波/锯齿波/方波，**无需任何外部音频资源文件，纯代码合成背景低频环境音、爆炸声与道具拾取音效**）。
* **数据持久化：** 基于 `localStorage` 的轻量级本地最高分排行榜。
