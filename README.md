# 🌊 Abyss Dash (深渊冲刺)

**Abyss Dash (深渊冲刺)** 是一款采用 HTML5 Canvas 和原生 JavaScript 打造的高品质、深海赛博朋克风 Endless Runner (无尽跑酷) 游戏。在幽暗深邃的海底，你将扮演一条小鲨鱼，不断下潜、吞噬小鱼、进化突破，并迎战潜伏在深海的恐怖巨兽！

## ✨ 核心特色 (Features)

*   **🎮 极致丝滑的操控体验**：完全支持鼠标、触屏和键盘 (Space/Arrow Keys) 操作，适配 PC 与移动端。
*   **🐟 吞噬与冲刺系统**：吃掉特定数量的小鱼可以积攒“狩猎值”，满后进入无敌的“冲刺模式 (Dash)”，瞬间撕裂所有障碍！
*   **🦈 史诗级 Boss 战**：
    *   随着下潜深度的增加，你将遭遇深海霸主：**机械变异章鱼**、**武装深海潜艇** 以及 **传说中的巨齿鲨**。
    *   **和平逃脱 (Pacifist Boss Victory)**：如果你能仅凭走位在 Boss 战中存活 60 秒而不进行攻击，Boss 将会因为无聊而主动撤退，并奖励你双倍分数和“和平胜利”特殊提示！
*   **🎨 顶级赛博深海美学**：
    *   使用现代 Glassmorphism (毛玻璃) UI 风格。
    *   极其炫酷的 Neon (霓虹) 色彩搭配与全息扫描线交互反馈。
    *   基于算法动态生成的海底洋流、粒子特效与环境水草。
*   **🏆 完善的成就与收集系统**：
    *   内置 15+ 种特色成就（包括极其硬核的“和平主义者”挑战）。
    *   深海图鉴 (Encyclopedia)：记录你遇到过的所有海洋生物和危险障碍。
    *   皮肤系统 (Skin Selector)：解锁并更换各种炫酷的鲨鱼外观。
*   **⚙️ 个性化设置 & 隐藏彩蛋**：支持 BGM 和音效独立调节，并在主菜单埋藏了开发者测试用的“无敌作弊模式”彩蛋。

## 🚀 游玩方法 (How to Play)

直接在浏览器中打开 `index.html` 即可开始游玩，无需任何后端环境或构建步骤。

1.  **移动/下潜**：按住鼠标左键、触摸屏幕或按住空格键，鲨鱼会加速下潜。松开则会受到浮力影响上浮。
2.  **吞噬进食**：碰触绿色或金色的发光小鱼即可进食，增加分数并恢复狩猎条。
3.  **避开危险**：躲开水雷、电水母以及海沟岩壁，否则会损失生命或被麻痹。
4.  **击杀 Boss**：在“冲刺模式 (Dash)”期间，你的鲨鱼是无敌的。利用冲刺直接撞击 Boss 即可对其造成伤害！

## 🛠️ 技术栈 (Tech Stack)

*   **前端核心**：Vanilla JavaScript (ES6+), HTML5 Canvas 2D API
*   **视觉与 UI**：CSS3 (Flexbox/Grid, CSS Variables, Animations, Glassmorphism Backdrop-filter)
*   **音频系统**：Web Audio API (动态合成音效，无需外部音频文件依赖)
*   **本地存储**：`localStorage` (用于持久化保存高分、成就进度和已解锁皮肤)

## 🤝 贡献与修改

这是一个单文件、轻量级但功能完整的 Web 游戏架构。所有的系统（实体管理、粒子系统、成就系统、Boss系统）都被封装成了独立的 JavaScript Class，非常易于扩展和二次开发。如果你想添加新的 Boss 或生物，可以直接在 `EntityManager` 和 `BossSystem` 中编写你的逻辑！
