> 一款基于 HTML5 原生 Canvas 的反重力深海动力学跑酷游戏。
> **单文件、零依赖、纯原生、全端自适应、开箱即玩。**

## 🌊 核心特色玩法

* **物理俯仰操作：** 摒弃传统的“按键跳跃”，采用“按住下潜，松开上浮”的深海浮力模拟。实体随速度引入 **Pitch 俯仰角自适应旋转**，操作反馈极具流体质感。
* **极致爽感与心流：** 吞噬具备精细动捕效果的潜鱼积攒狩猎值，满怒即可触发【猩红冲刺】——无敌霸体+撞碎一切暗礁。
* **全新道具生态：** 引入【电磁磁铁】自动吸附方圆 300px 内的所有鱼群；【量子护盾】可完美抵御一次致命撞击。
* **动态环境质变：** 独创 **Depth 变色机制**，随着潜入越深，场景平滑陷入午夜超深海；超过 300 分将遭遇具备**变频追踪算法**的智能水雷，极限施压。

## 🛠️ 技术亮点与工程实践

本项目不依赖任何第三方游戏引擎（如 Cocos/Egret）或前端框架，从零手写物理、渲染与状态控制，重点攻坚了以下核心问题：

| 工程痛点 | 产生的现象 | 解决方案与架构 |
| :--- | :--- | :--- |
| **全生态动态变色** | 随着跑酷距离增加，单一的背景色容易产生视觉疲劳，且无法体现“下潜深渊”的逼真感。 | **色域空间线性插值算法 (Color Space Lerp)：** 提取深度系数，让天空光、山脉、前景植物的 RGB 像素随分数实时平滑演变，并在中后期无缝渲染由内向外的**径向渐变迷雾暗角 (Radial Vignette)**。 |
| **运动俯仰角缺失** | 鲨鱼在垂直位移（Y轴）剧烈变动时，若角度始终水平，会产生极其僵硬的浮空感。 | **动态刚体旋转 (Rigid Body Rotation)：** 每帧提取 $shark.velocity$ 矢量，通过弧度矩阵叠加 $ctx.rotate$。实现操控时“下潜低头、上浮挺胸”的流体仿生动态。 |
| **视差无缝滚屏** | 前景植物在移出画布左侧进行循环再生成时，非线性计算容易导致物体边缘突兀闪烁、产生断层。 | **双模余数自适应公式 (Modulus Wrapping)：** 重写坐标滚动公式 `((i * 250 - frame * 0.5) % (w + 250) + (w + 250)) % (w + 250) - 100`，完美抹平边缘越界，实现永不断层的丝滑无缝平移。 |
| **移动端强行竖屏** | 手机玩家误以竖屏方式点开游戏时，由于 Canvas 是 900×500 宽屏比例，会导致画面被严重挤压变形。 | **移动端横屏防呆锁 (Orientation Locker)：** 拦截 `touchstart` 并利用 CSS 媒体查询 `@media screen and (orientation: portrait)`，在竖屏时强制拉起赛博风的全屏 Overlay 提示，自动阻断不规范手势。 |
| **引力场物理计算** | 磁铁吸附小鱼时，如果直接更改坐标会产生生硬的瞬间瞬移。 | **线性插值缓动 (Lerp Approaching)：** 基于 Math.hypot 建立半径 300px 的电磁感应区，对区域内小鱼运用弹性缓动插值算法，实现丝滑的平滑吸附特效。 |
| **刷新率依赖** | 144Hz/240Hz 屏幕下游戏运行速度是 60Hz 的数倍，导致高刷屏玩家必定暴毙。 | **工业级时间步长 (Fixed Time Step)：** 引入时间累加器（Accumulator），强制逻辑帧锁定 120Hz 更新，彻底剥离物理逻辑与渲染帧率。 |

## 💻 技术栈

* **渲染层：** HTML5 `<canvas>` 2D API 纯代码绘制特效（双重矩阵相机震屏、径向自适应暗角、刚体转角、鱼体细节动捕、发光粒子、视差远山、无缝海藻）。
* **音频引擎：** Web Audio API（基于代码手搓合成器底层，生成三角波/锯齿波/方波，**无需任何外部音频资源文件，纯代码合成背景低频环境音、爆炸声与道具拾取音效**）。
* **数据持久化：** 基于 `localStorage` 的轻量级本地最高分排行榜。
