# 🦈 深渊冲刺 (Abyss Dash) - Ultra HD v4.5

> 一款基于 HTML5 原生 Canvas 的反重力深海跑酷游戏。
> **单文件、零依赖、纯原生、开箱即玩。**

[![GitHub Pages](https://img.shields.io/badge/🎮主站试玩-GitHub_Pages-00ffff?style=for-the-badge)](https://guofudamo2007-lab.github.io/AbyssDash/)

## 🌊 核心特色玩法

* **反直觉物理操作：** 摒弃传统的“按键跳跃”，采用“按住下潜，松开上浮”的深海浮力模拟，带来极具新鲜感的下潜体验。
* **极致爽感与心流：** 吞噬发光小鱼积攒狩猎值，满怒即可触发【猩红冲刺】——无敌霸体+撞碎一切暗礁。
* **全新道具生态：** 引入【电磁磁铁】自动吸附方圆 300px 内的所有鱼群；【量子护盾】可完美抵御一次致命撞击。
* **高阶动态危机：** 分数超过 300 后，深海将生成具备**变频追踪算法**的智能水雷，实时锁定玩家 Y 轴，极限施压。
* **高阶视觉阻断：** 引入大范围【视差远山山脉】与前景【动态摇摆海藻】，构建多层纵深深海场景，极具街机艺术感。

## 🛠️ 技术亮点与工程实践

本项目不依赖任何第三方游戏引擎（如 Cocos/Egret）或前端框架，从零手写物理、渲染与状态控制，重点攻坚了以下核心问题：

| 工程痛点 | 产生的现象 | 解决方案与架构 |
| :--- | :--- | :--- |
| **引力场物理计算** | 磁铁吸附小鱼时，如果直接更改坐标会产生生硬的瞬间瞬移。 | **线性插值缓动 (Lerp Approaching)：** 基于 Math.hypot 建立半径 300px 的电磁感应区，对区域内小鱼运用弹性缓动插值算法，实现丝滑的平滑吸附特效。 |
| **动态寻轨 AI** | 后期障碍物固定移动过于死板，无法对高技术玩家形成有效威胁。 | **变频追踪算法 (Dynamic Tracking)：** 水雷引入独立轴向速度，每帧实时对冲鲨鱼的坐标，形成兼顾横向推进与纵向狙击的追踪机制。 |
| **状态机生命周期** | 游戏死亡或暂停时，主循环停止导致游戏无法渲染结算红屏或残留最后一帧。 | **主状态机非阻塞渲染：** 隔离 updateLogic 与 draw。在非 PLAYING 状态下，通过解耦的条件分支，确保 GAMEOVER 结算弹窗和静止界面能实时接受主循环的驱动刷新。 |
| **视觉盲区遮挡** | 玩家操纵鲨鱼逼近左上角核心数据面板时，UI 容易遮挡视野导致暴毙。 | **动态视焦避让 (Alpha Transparency Drop)：** 实时监控坐标，当鲨鱼进入左上角触发区（x<320, y<140）时，动态将 UI 面板不透明度下调至 0.25，移开后恢复。 |
| **高分屏画质发虚** | 在 Mac Retina 屏幕或高配手机上，Canvas 边缘出现明显锯齿和模糊。 | **逻辑与物理分辨率解耦：** 引入 `devicePixelRatio` 动态计算屏幕像素比，利用 `ctx.scale` 重新映射绘制坐标系，实现像素级锐利。 |
| **刷新率依赖** | 144Hz/240Hz 屏幕下游戏运行速度是 60Hz 的数倍，导致高刷屏玩家必定暴毙。 | **工业级时间步长 (Fixed Time Step)：** 引入时间累加器（Accumulator），强制逻辑帧锁定 120Hz 更新，彻底剥离物理逻辑与渲染帧率。 |

## 💻 技术栈

* **渲染层：** HTML5 `<canvas>` 2D API 纯代码绘制特效（双重矩阵相机震屏、量子护盾、动态鱼尾摆动、发光文字、爆炸粒子、视差远山、前景海藻）。
* **音频引擎：** Web Audio API（基于代码手搓合成器底层，生成三角波/锯齿波/方波，**无需任何外部音频资源文件，纯代码合成背景低频环境音、爆炸声与道具拾取音效**）。
* **数据持久化：** 基于 `localStorage` 的轻量级本地最高分排行榜。
