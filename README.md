# 深渊冲刺 / Abyss Dash

&gt; 一个基于原生 Canvas 的深海冲刺游戏。单文件，零依赖，部署即玩。

## 在线试玩
[Netlify 链接]

## 核心机制
- 点击/空格下潜，松开上浮
- 吃小鱼攒怒气，满怒触发冲刺（无敌 + 破障）
- 洋流加速，水母麻痹

## 解决过的关键问题
| 问题 | 现象 | 方案 |
|------|------|------|
| 刷新率相关速度 | 144Hz 比 60Hz 快 2.4 倍 | 固定时间步长 + accumulator 模式 |
| 速度无限增长 | 后期无法反应 | 非线性加速曲线 + 硬上限 |
| 状态生命周期 | 暂停键第二条命消失 | 显式状态机，重置时全量校验 |
| 移动端适配 | 手机只显示一半 | Canvas 物理尺寸与 CSS 尺寸分离 |

## 技术栈
原生 JS / Canvas 2D / Web Audio API。无框架，无构建工具。
