# 🦈 深渊冲刺 (Abyss Dash)

> 一款基于 HTML5 原生 Canvas 的反重力深海跑酷游戏。
> **单文件、零依赖、纯原生、开箱即玩。**

[![GitHub Pages](https://img.shields.io/badge/🎮主站试玩-GitHub_Pages-00ffff?style=for-the-badge)](https://guofudamo2007-lab.github.io/AbyssDash/)
[![Netlify](https://img.shields.io/badge/🚀备用节点-Netlify-33ffaa?style=for-the-badge)](https://cheerful-bienenstitch-28078d.netlify.app/)

## 🌊 核心特色玩法

* **反直觉物理操作：** 摒弃传统的“按键跳跃”，采用“按住下潜，松开上浮”的深海浮力模拟，带来极具新鲜感的下潜体验。
* **极致爽感与心流：** 吞噬发光小鱼积攒狩猎值，满怒即可触发【猩红冲刺】——无敌霸体+撞碎一切暗礁。
* **全新道具生态：** 引入【电磁磁铁】自动吸附方圆 250px 内的所有鱼群；【量子护盾】可完美抵御一次致命撞击。
* **高阶动态危机：** 分数超过 300 后，深海将生成具备**变频追踪算法**的智能水雷，实时锁定玩家 Y 轴，极限施压。

## 🛠️ 技术亮点与工程实践

本项目不依赖任何第三方游戏引擎（如 Cocos/Egret）或前端框架，从零手写物理、渲染与状态控制，重点攻坚了以下核心问题：

| 工程痛点 | 产生的现象 | 解决方案与架构 |
| :--- | :--- | :--- |
| **引力场物理计算** | 磁铁吸附小鱼时，如果直接更改坐标会产生生硬的瞬间瞬移。 | **线性插值缓动 (Lerp Approaching)：** 基于 Math.hypot 建立半径 250px 的电磁感应区，对区域内小鱼运用弹性缓动插值算法，实现丝滑的平滑吸附特效。 |
| **动态寻轨 AI** | 后期障碍物固定移动过于死板，无法对高技术玩家形成有效威胁。 | **变频追踪算法 (Dynamic Tracking)：** 水雷引入独立轴向速度，每帧实时对冲鲨鱼的 sharkCY 坐标，形成兼顾横向推进与纵向狙击的追踪机制。 |
| **状态状态机解耦** | 护盾、无敌、麻痹、洋流加速等多种状态叠加时，极易产生逻辑冲突（如护盾碎裂时误判死亡）。 | **多层次状态优先级判定：** 在 Class 状态机中重构伤害判定链。判定优先级严格划分为：无敌霸体（冲刺/洋流） > 护盾消耗 > 实体碰撞/实体销毁。 |
| **高分屏画质发虚** | 在 Mac Retina 屏幕或高配手机上，Canvas 边缘出现明显锯齿和模糊。 | **逻辑与物理分辨率解耦：** 引入 `devicePixelRatio` 动态计算屏幕像素比，利用 `ctx.scale` 重新映射绘制坐标系，实现像素级锐利。 |
| **刷新率依赖** | 144Hz/240Hz 屏幕下游戏运行速度是 60Hz 的数倍，导致高刷屏玩家必定暴毙。 | **工业级时间步长 (Fixed Time Step)：** 引入时间累加器（Accumulator），强制逻辑帧锁定 120Hz 更新，彻底剥离物理逻辑与渲染帧率。 |
| **数值崩坏** | 后期障碍物密不透风，且叠加洋流加速后画面完全失控。 | **平滑动态难度 (Dynamic Scaling)：** 将基础速度（线性增长）与障碍生成频率（对数衰减）解耦，并引入**绝对速度硬上限 (Hard Cap)**。 |

## 💻 技术栈

* **渲染层：** HTML5 `<canvas>` 2D API 纯代码绘制特效（虚线磁力环、粒子水雷闪烁、量子护盾光晕、发光残影）。
* **音频引擎：** Web Audio API（基于代码手搓合成器底层，生成三角波/锯齿波/方波，**无需任何外部音频资源文件，纯代码合成爆炸声与道具拾取音效**）。
* **数据持久化：** 基于 `localStorage` 的轻量级本地最高分排行榜。
