# 🦈 深渊冲刺 (Abyss Dash) - v5.0 Milestone

> 一款基于 HTML5 原生 Canvas 的反重力深海动力学跑酷游戏。
> **单文件、零依赖、纯原生、全端视口自适应、开箱即玩。**

## 🌊 核心特色玩法

* **生态区域演进 (Biome System)：** 随着下潜深度的增加，玩家将依次穿越【浅海】、【沉船区】、【海沟】与【黑暗区】。不同海域具有完全独立的危险系数、敌机刷新频率与专属障碍物（如沉船区的交叉钢筋）。
* **极速连击倍率 (Combo Multiplier)：** 连续吞噬 3 条发光小鱼即可激活 `COMBO! x2` 极速状态，得分效率翻倍！受到任何硬碰撞或麻痹伤害将瞬间打断连击，极限拉满“富贵险中求”的街机心流。
* **流体动力学操控：** 采用“按住下潜，松开上浮”的浮力模拟。角色随垂直运动速度引入 **Pitch 俯仰角自适应旋转矩阵**，操作反馈极具灵动的流体质感。
* **次世代视觉反馈：** 吞噬具备多边形尾鳍及眼部微观动态的小鱼积攒怒气，满怒触发【猩红冲刺 RUSH】——激活超高速镜头动态线条、无敌霸体、全屏暗礁碎裂特效及独立物理相机震荡 (Camera Shake)。
* **环境动态演变：** 独创 **Depth 深度矩阵**，天空光 rays、远山、前景植物以及海水色域将随分数平滑陷入午夜超深海，并叠加动态径向迷雾暗角 (Vignette)。

## 🛠️ 技术亮点与工程实践

本项目拒绝依赖任何第三方现代游戏引擎（如 Cocos/Egret）或重量级框架，纯手写底层物理、逻辑状态、渲染管线与音频合成，核心攻坚了以下工业级痛点：

| 工程痛点 | 产生的现象 | 解决方案与架构 |
| :--- | :--- | :--- |
| **DOM 动画重置失效** | 在同一区域连续触发 Combo 提示词时，CSS 过渡动画无法二次播放。 | **强制同步重排 (Forced Reflow)：** 在移除和添加动画类名之间，巧妙插入 `void element.offsetWidth` 触发浏览器强制重绘，实现 DOM 动画的无缝重置与高频触发。 |
| **视口跨端缩放** | 传统 HTML5 游戏在面对全面屏手机、iPad 等多尺寸设备时，UI 字体易错位或被裁剪。 | **高级容器查询架构 (Container Query Units)：** 将外层声明为 size 容器，UI 抛弃 px 和 vw，全量改用 `cqw` / `cqh` 容器单位进行相对缩放，实现完美的长宽比动态保真。 |
| **多区域状态耦合** | 后期难度提升若仅靠单一数值线性增长，会导致游戏节奏同质化。 | **解耦的生态状态机 (Biome State Machine)：** 引入区域判定器，将鱼群、水母、水雷的生成频率与当前所处 `currentZoneName` 严格绑定，构建了阶梯式的难度曲线。 |
| **视差无缝滚屏** | 前景植物在移出画布左侧进行循环再生成时，非线性计算容易导致物体边缘突兀闪烁。 | **双模余数自适应公式 (Modulus Wrapping)：** 重写坐标滚动公式，物理抹平边缘越界，实现永不断层的丝滑无缝跑马灯滚动。 |
| **移动端强行竖屏** | 手机玩家误以竖屏方式点开游戏时，画面被严重挤压变形。 | **移动端横屏防呆锁 (Orientation Locker)：** 利用 CSS 媒体查询 `@media screen and (orientation: portrait)`，在竖屏时强制拉起赛博风 Overlay 提示，自动阻断不规范手势。 |
| **高分屏画质发虚** | 在 Mac Retina 屏幕或高配手机上，Canvas 边缘出现明显锯齿。 | **逻辑与物理分辨率解耦：** 引入 `devicePixelRatio` 动态计算屏幕像素比，利用 `ctx.scale` 重新映射绘制坐标系，实现像素级锐利。 |

## 💻 技术栈

* **文本视觉：** 远程无缝挂载 Google Web Fonts 工业级赛博风格字体（Orbitron / Rajdhani）。
* **渲染层：** HTML5 `<canvas>` 2D API 纯代码绘制特效（UI容器响应、双重矩阵相机震屏、生态区域切换提示、刚体俯仰角、鱼体微观渲染）。
* **音频引擎：** Web Audio API（基于代码手搓合成器底层，**无需任何外部 .mp3 资源文件，纯代码合成背景低频环境音、方波爆炸声与正弦波拾取音**）。
* **数据持久化：** 基于 `localStorage` 的轻量级本地最高分排行榜。
