> **单文件、零依赖、纯原生、全端视口自适应、自带深海图鉴。**

## 🌊 核心特色玩法

* **沉浸式枢纽与图鉴 (Interactive Hub)：** 拥有完整的赛博风格主菜单界面与《深海图鉴》系统。即使处于待机菜单，底层引擎依旧在演算背景深海生态的浮动粒子与游鱼。
* **生态区域演进 (Biome System)：** 随着下潜深度的增加，无缝穿越【浅海】、【沉船区】、【海沟】与【黑暗区】四大生态。各区域拥有独立的危险系数与专属障碍物。
* **极速连击倍率 (Combo Multiplier)：** 连续吞噬 3 条发光小鱼即可激活 `COMBO! x2` 极速状态，得分效率翻倍！受到任何硬碰撞或麻痹伤害将瞬间打断连击。
* **流体动力学操控：** 采用“按住下潜，松开上浮”的浮力模拟。角色随垂直运动速度引入 **Pitch 俯仰角自适应旋转矩阵**，操作反馈极具流体质感。
* **次世代视觉反馈：** 满怒触发【猩红冲刺 RUSH】——激活超高速镜头动态线条、无敌霸体、全屏暗礁碎裂特效及独立物理相机震荡 (Camera Shake)。
* **环境动态演变：** 独创 **Depth 深度矩阵**，天空光、远山、前景植物以及海水色域将随分数平滑陷入午夜超深海，并叠加动态径向迷雾暗角 (Vignette)。

## 🛠️ 技术亮点与工程实践

本项目拒绝依赖任何第三方游戏引擎（如 Cocos/Egret）或重量级前端框架，纯手写底层物理、逻辑状态、渲染管线与音频合成，核心攻坚了以下工业级痛点：

| 工程痛点 | 产生的现象 | 解决方案与架构 |
| :--- | :--- | :--- |
| **状态机生命周期死锁** | 游戏处于菜单或结算界面时，主循环停止导致背景冻结、动画失效。 | **独立状态渲染解耦 (Decoupled State Machine)：** 剥离出 `updateMenuLogic` 与主 `updateLogic`。在 `MENU` 状态下，系统只演算背景鱼群与气泡，完美实现动态待机画面。 |
| **DOM 动画重置失效** | 高频触发 Combo 连击或区域切换词时，CSS 过渡动画无法二次播放。 | **强制同步重排 (Forced Reflow)：** 在移除和添加动画类名之间，精准插入 `void element.offsetWidth` 触发浏览器强制重绘，实现 DOM 动画的无缝重置。 |
| **视口跨端极光缩放** | HTML5 游戏在面对全面屏手机、iPad 等多尺寸设备时，UI 极易错位。 | **高级容器查询架构 (Container Query Units)：** 将最外层声明为 size 容器，UI 抛弃 px 和 vw，全量改用 `cqw` / `cqh` 相对单位进行缩放，实现完美的长宽比动态保真。 |
| **全生态动态变色** | 跑酷距离增加时，单一背景色无法体现“下潜深渊”的压迫感。 | **色域空间线性插值算法 (Color Space Lerp)：** 提取深度系数，让场景 RGB 像素随分数实时平滑演变，并在后期无缝渲染径向渐变迷雾暗角。 |
| **移动端强行竖屏** | 手机玩家误以竖屏方式点开游戏时，画面被严重挤压变形。 | **移动端横屏防呆锁 (Orientation Locker)：** 结合 CSS 媒体查询 `@media screen and (orientation: portrait)` 与触控拦截，在竖屏时强制拉起 Overlay 遮罩阻断非法手势。 |

## 💻 技术栈

* **文本视觉：** 远程无缝挂载 Google Web Fonts 工业级赛博风格字体（Orbitron / Rajdhani）。
* **渲染层：** HTML5 `<canvas>` 2D API 纯代码绘制特效（UI容器响应、双重矩阵相机震屏、生态区域动态切换、刚体俯仰角流体动捕）。
* **音频引擎：** Web Audio API（基于代码手搓合成器底层，**无需任何外部素材文件，纯代码实时生成环境低音、方波爆炸声与正弦波拾取音**）。
